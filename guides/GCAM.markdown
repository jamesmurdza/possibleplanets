How to run the GCAM integrated assessment model:

## Run with Docker

GCAM isn't a pip-installable Python package like most of the other models
here -- it's a large compiled C++17 program (`gcam.exe`) that reads a
multi-gigabyte input database generated by a separate R data pipeline.
Building all of that yourself is a multi-hour undertaking, so this is the
one model on this site where Docker isn't just the convenient option --
it's the realistic one.

If necessary, download and install Docker: [Link](https://www.docker.com/products/docker-desktop/).

A prebuilt image (with the compiled binary and its full input database
already baked in) is published on Docker Hub:

```
docker pull possibleplanets/gcam
docker run --rm possibleplanets/gcam
```

This runs the "Reference" scenario (GCAM's full 1975-2100 reference
case, in 5-year steps) and prints the result as JSON once it finishes.
`SCENARIO_PARAMS` is also accepted as an environment variable, but
"Reference" is currently the only supported scenario -- GCAM's own
other bundled configurations weren't validated against this image, so
they're not exposed yet:

```
docker run --rm -e SCENARIO_PARAMS='{"scenario": "Reference"}' possibleplanets/gcam
```

A few things that make GCAM a different experience from every other
model on this site:

- **The image is large** -- several gigabytes, mostly the pre-generated
  input database GCAM itself needs to run (GCAM's data-prep step needs
  far more memory than a typical laptop has, so that step is already
  done for you and baked into the image rather than something this
  container runs itself).
- **A run takes about half an hour**, not seconds -- GCAM is solving a
  real multi-region economic equilibrium across 21 time periods, not a
  closed-form calculation.
- Expect the container to use close to 4 CPUs and several GB of memory
  while it runs.
